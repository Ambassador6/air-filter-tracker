# Broader Ideas Air Filter Tracker

This is the finished installable Android-friendly version of the Air Filter Tracker as a Progressive Web App (PWA).

Features:
- Properties and units
- Filter-change records
- Date changed, filter size, performed by, next-change date
- Maintenance records
- Contractor, project cost, and payment method (Check, Cash, Cash App)
- Dashboard with units, filter records, maintenance, and filters due
- Local/offline data storage on the phone
- Broader Ideas Air Filter Tracker icon
- Add-to-home-screen support

## Install on Android
1. Put this folder on a secure HTTPS web host (or use a local web server on your network).
2. Open the site in Chrome on the Android phone.
3. Use Chrome's menu and choose "Add to Home screen" / "Install app".
4. The app then opens as a standalone app.

## Important
The app stores its records locally in the browser on the phone. Clearing the browser's site data can remove records, so a cloud backup/database can be added in the next version.

An APK cannot be compiled in this workspace because the Android SDK/build tools are not installed and this environment cannot download them. The included PWA is nevertheless a real installable Android app experience and is ready to host.
